# Model House Planning Rules

These are standing King’s Finances rules for each monthly closeout.

- **Price Used:** current listing price less **2.5%**, rounded to the nearest **$1,000**. Use an explicit override only when property-specific evidence supports it.
- **Mortgage rate:** refresh at every monthly closeout using current top-tier conventional 30-year pricing for an approximately **800 credit score** and the actual down-payment / LTV profile.
- **Rate-shopping assumption:** plan for an aggressively shopped rate rather than simply using the broad headline market average.
- **Seller concessions:** do not include seller-paid points or temporary buydowns in the base case unless explicitly modeled.
- Recalculate loan amount, P&I, total monthly housing payment, and gross income target whenever list price or rate changes.
- Keep the existing model-house UI labels unchanged.
